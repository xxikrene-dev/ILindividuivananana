Tentang saya

Perkenalkan, nama saya M. Ivana Soejanto dari kelas 94 nomor absen 26, SMP Santa Ursula Jakarta. Melalui kesempatan ini, saya merancang dan membangun website yang mengangkat tema besar mengenai SDG 13 (Climate Action) sebagai bentuk kepedulian saya terhadap masa depan bumi. Bagi saya pribadi, perubahan iklim bukan sekadar isu lingkungan biasa, melainkan salah satu faktor paling krusial yang secara langsung memengaruhi kesejahteraan, keamanan, dan keberlangsungan hidup masyarakat manusia dalam skala global. Oleh karena itu, melalui platform digital ini, saya ingin menuangkan pemahaman sekaligus mengajak setiap pembaca untuk lebih peka dan tergerak mengambil langkah nyata demi menjaga kelestarian lingkungan kita bersama.

Selain didorong oleh rasa kepedulian yang mendalam terhadap isu krisis iklim, pembuatan website ini juga disusun secara sungguh-sungguh untuk memenuhi tujuan akademik dalam proyek Integrated Learning (IL) individu. Proyek ini merupakan bentuk kolaborasi terpadu dari tiga mata pelajaran utama, yakni PPKn, IPS, dan TIK, yang melatih saya untuk mengintegrasikan kemampuan analisis sosial, pemahaman kewarganegaraan global, serta keterampilan teknologi informasi ke dalam satu karya yang utuh serta teknit TIK software visual studio code menggunakan html css untuk membaut website ini. Dengan dedikasi dan ketekunan dalam proses pengerjaannya, saya berharap website ini tidak hanya membuahkan hasil nilai akademik yang optimal, tetapi juga mampu menjadi media edukasi yang bermanfaat dan menginspirasi banyak orang.
